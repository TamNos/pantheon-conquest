# Pantheon Game Project

## Project Structure
The Pantheon game project is organized into the following structure:

```
/pantheon
 ├── /assets         # Contains game assets such as images, sounds, and fonts.
 ├── /src            # Source code for the game.
 │    ├── /components # Common components used in the game.
 │    ├── /scenes     # Scene definitions and logic.
 └── /tests          # Unit and integration tests.
```

## Quick Start Guide
To get started with the Pantheon game project, follow these steps:
1. Clone the repository:  
   `git clone https://github.com/TamNos/pantheon-conquest.git`
2. Navigate to the project directory:  
   `cd pantheon-conquest`
3. Install dependencies:  
   `npm install`
4. Run the development server:  
   `npm start`

Now you can access the game in your browser at `http://localhost:3000`.

## Tech Stack
The Pantheon game is built using the following technologies:
- JavaScript (ES6)
- React.js for UI development
- Node.js for the backend
- Webpack for module bundling
- Jest for testing
